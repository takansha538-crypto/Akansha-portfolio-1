# Akansha's Portfolio Website

A responsive portfolio made with HTML, CSS and vanilla JavaScript.

## 1. Open the project
- Extract `my-portfolio.zip`.
- Open the extracted `my-portfolio` folder in VS Code.

## 2. Add your photo
- Put your own portrait photo in the `images` folder.
- Name it exactly `profile.jpg`.
- Recommended: a clear, front-facing portrait in JPG format.

## 3. Personalize before publishing
Search and replace these placeholders in `index.html`:
- GitHub and LinkedIn profile links and email are already filled in with the details you provided.

Also verify:
- Your name and college details.
- Expected graduation year (currently shown as 2028; change if needed).
- Project repository URLs and live demo URLs.
- Skill levels and project descriptions.

## 4. Add your resume
- Copy your latest resume PDF into the main `my-portfolio` folder.
- Name it `resume.pdf`.
- The Download Resume button will then work.

## 5. Run locally
- Open `index.html` in a browser, or use the VS Code Live Server extension.
- Internet is needed for the Google Fonts used by the design.

## 6. Publish with GitHub Pages
1. Create a GitHub repository, for example `my-portfolio`.
2. Upload all files and folders (including `images/profile.jpg` and `resume.pdf`).
3. Open repository Settings -> Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. Your URL will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/my-portfolio/`

## Important
Do not publish until you have replaced all placeholders and checked every link. The current photo is intentionally not included; add your own photo.
